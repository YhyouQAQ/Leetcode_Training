# Leetcode_Training
my own coding solution
All my effort was for to build a world where we can understand each other easily.
我是教育信管系的学生，这个专业并不知道自己的目标，
也巧，既然我有一个执着的目的，就让我成为北斗之星。
我的同学们都没有我在编程精通，他们学习C语言时，跟不上我们老师的速度。
在讲结构体时，他们就完全跟不上了，云里雾里。
学习编程对于我尤其没有像对于他们一样难，我早就来过这片地方，眼睛可以看穿雾径。
我也是淋过雨的人，也想为别人撑一把伞，哪怕这场雨是另一场雨。
我曾从政治教科书中自行顿悟到了很多，不满的是教材的简陋、防御与不用心。
我曾从老师的讲课中自行顿悟到了很多，不满的是讲解的不得要点，
我曾经得到了很多有用的知识点，写得出来，却不能参与教育体系，
不满的是教育体系对学生参与的排斥，学习再生产的忽视。
因此，我有对教育最沉切的恨和对教育最深沉的爱。
你知道我要说什么，只要我还不被你忘记，这就是执着。
